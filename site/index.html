    06 / METHOD
    Five questions about preservation
    1. 1
      Writer
      Compare write(rich) and write(degraded) bytes. Diff means expressed; same means cannot express.
    2. 2
      Round trip
      Compare both written inputs after reading. Diff means survives; same means lost.
    3. 3
      Exact
      Compare read(write(rich)) to rich: exact, canonical, or lossy.
    4. 4
      Metadata
      Recover ten metadata shapes from standalone output: exact, partial, or lost.
    5. 5
      Carve source
      Compare source, AST, then rendered HTML: exact, equivalent, respelled, or lossy. Conversion failures are err.
    Preserve wrapping
    --wrap=preserve keeps SoftBreak from becoming a space during writing.
    Resolve resources
    --resource-path=fixtures and the same server image prevent a missing resource from looking like exact recovery.
    Canonical folds
    Default and left alignment, measured and default column widths, raw tex and latex aliases, and invented header IDs are folded. Exact recovery keeps these distinctions.
    The first two lanes compare the converted pair, never the input. A distinction surviving does not imply exact recovery.
    

    07 / BOUNDARIES
    What the grid can tell you
    Expression is not quality
    A writer diff only means it distinguishes the inputs. Escaping to raw HTML counts.
    Errors and the host machine
    Muse and typst can emit headings their own readers reject. OPML serializes outlines rather than documents, so most probes error. PDF needs an external TeX engine; its errors measure the machine.
    Single features
    Probes isolate one feature. Interactions between features are not measured. Bibliography databases and the json/xml AST serializations are excluded from comparable round-trip formats; native remains the reference.
    Carve comparison boundaries
    Carve round trips compare blocks and only metadata keys present in the source. Invented EPUB date, UUID, and language are excluded. EPUB, fb2, and ipynb container chrome is stripped, as in the exact lane. Carve features absent from pandoc's AST need separate source fixtures.
    Severity choices
    Strikeout and scripts count as structure because flattening changes what the text asserts. Captions, table footers, and figures count as content because their degraded input omits those words.
    Measurement date
    The date comes from the recorded measurement, not the website build. Reports under docs are snapshots regenerated with results.
